[DEV]

Game by Lulu started in 2024
Written in PASCAL with the the amazing open source duo: Lazarus IDE and FreePascal compiler!

The following libraries are used for its development:
- BGRABitmap to handle fonts, images and svg files. Thanks circular!
- OGLCScene a 2D game engine which use OpenGL 3.3 capabilities to render graphics  https://github.com/Lulu04/OGLCScene
- ALSound to play sounds and musics  https://github.com/Lulu04/ALSound
